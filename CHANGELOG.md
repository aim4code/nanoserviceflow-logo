# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-11-01

### Added

- Geometry sliders for **arm length** (the arm's start point at the core stays
  fixed), **mini-module size**, and **mini-module count**. With the new sliders at
  their defaults, the logo renders exactly as in 1.0.0.

## [1.0.0] - 2026-07-10

### Added

- Parametric NanoServiceFlow logo generator (`NanoServiceFlow Logo.html`) — a
  single-file, zero-dependency web tool for generating the brand logo and
  per-module variants (module presets, color/icon pickers, geometry sliders,
  background variants, mark-only symbols, SVG export, and setup export/import).
- `README.md` documenting the project's purpose, background, and usage
  instructions, with a screenshot of the tool and a link to the
  [NanoServiceFlow](https://github.com/aim4code/nanoserviceflow) library.
- `.gitignore` for a static, dependency-free web project.
- `.claude/launch.json` local static-server preview configuration.
